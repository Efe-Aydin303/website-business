# Demo: The Corner Hengelo

Snackbar, Dennenbosweg 92, Hengelo. Tel 074 737 0119. Opent in november 2026 (grand opening hele maand).
Alles komt van hun flyer (`flyer.jpg`). Niks verzonnen.

## Nog invullen (staat oranje/schuin op de site)
- Openingstijden
- Volledige menukaart met prijzen
- Soorten burgers
- Postcode-letters (flyer is afgesneden: "7556 G?")

## Online zetten (Cloudflare Pages, gratis)
1. Log in op dash.cloudflare.com, ga naar **Workers & Pages**, dan **Create**, tab **Pages**, **Upload assets**.
2. Projectnaam: `the-corner-hengelo`.
3. Sleep deze map (`index.html` + `flyer.jpg`) erin en klik **Deploy**.
4. Klaar: https://the-corner-hengelo.pages.dev
